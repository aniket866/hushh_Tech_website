How NDA signing actually works

The agreement packet is signed, stamped with evidence, and delivered entirely on Hushh's own stack. No e-signature vendor is involved at any point.

4 fund documents 13 tokens per document ESIGN Act / UETA No DocuSign

On the DocuSign question. There is no DocuSign integration, and no other e-signature vendor either. Signing is built in-house on the stack we already run: the website, one Supabase Edge Function, one Cloud Run service, and Gmail.

The diagram below reads in three lanes — what the investor does, what the server does, and what was built once, offline, long before any investor arrives.

  • WhiteWhat the investor sees and does in the browser.
  • MintA Hushh system step running on the server.
  • GoldEvidence and the certificate — the parts that make the signature hold up.
  • SlateBuild time. Runs once, offline, not per signature.
  • DashedA parallel path, or what happens when something fails.

What gets captured at the moment of signing

This is step 5 in the diagram, and it is the part that turns a form submission into a signature.

Evidence How it is captured Why it matters
Signer Typed name plus the account email Ties the act to a specific person
Intent An explicit tick agreeing to sign electronically, with the exact wording version recorded Shows they meant to sign, rather than clicked by accident
Signature ID A fresh unique code generated for this one signing event Lets any single signature be traced end to end
Time Both world-standard time and the signer's own local time Establishes when it happened, unambiguously
IP address Read from the server's own request headers — never accepted from the browser, because a browser can lie about it Independent evidence of where the signature came from
Device Browser and operating system Corroborates the signing session
Integrity A fingerprint calculated from the document's exact contents, fixed at build time Proves the document was not altered afterwards

The one idea worth taking away

Carving a rubber stamp is delicate work. You do it once, carefully, in the workshop — and if you carve it wrong, you find out immediately, not in front of a customer. Pressing that stamp onto paper is instant and almost impossible to get wrong.

That is exactly the split in the diagram. The bottom lane carves: it opens four Word files, cuts in the placeholder slots, attaches the certificate page, and refuses to finish if even one of the thirteen slots is missing. The middle lane presses: it swaps placeholders for real values and sends the email. An investor waiting on their screen only ever meets the press.
